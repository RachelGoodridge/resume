# Rachel Goodridge — Personal CV Website

This repository contains the source files for my personal academic CV website, built with [R Markdown](https://rmarkdown.rstudio.com/) and hosted via GitHub Pages.

## Site Structure

| File | Page |
|------|------|
| `index.Rmd` | About |
| `edu.Rmd` | Education |
| `exp.Rmd` | Experience |
| `proj.Rmd` | Projects |
| `pub.Rmd` | Publications |
| `pres.Rmd` | Presentations |
| `skills.Rmd` | Skills |

## Configuration

| File | Purpose |
|------|---------|
| `_site.yml` | Site-wide settings: navbar, output directory, theme |
| `custom.css` | Custom styling (typography, colors, layout) |
| `header.html` | Injected into `<head>` of every page (favicon, font preconnects, new-tab link script) |
| `footer.html` | Injected after `<body>` on every page |
